Use this exact structure:

{
"hook": "6 to 7 word hook phrase goes here",

"GUEST: [expr:0.X] Specific inquiry or detailed question?",
"HOST: [expr:0.X] Host explanation line"
]
}

Format Rules for the "script" array:

* The GUEST line MUST be a direct, topic-specific question ending with a question mark.
* All remaining lines in the script MUST be delivered by the HOST.
* Keep HOST expression values between 0.5 and 0.8.
* Keep GUEST expression values between 0.3 and 0.5.
